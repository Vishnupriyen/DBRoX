## Internal audit (twice a year: May and November)
Checked by someone who did not build the control (the independent tester agent plus the founder):

- [ ] Restore drill done each month, results match the manifest
- [ ] Activity-log chain check green every night; anchors in the bucket
- [ ] Alerts tested (stop the server, fake an old backup, wrong logins)
- [ ] Policies reviewed, versions current
- [ ] Supplier review done; incidents and corrective actions closed
- [ ] `deploy/verify-harden.sh` all ✔
