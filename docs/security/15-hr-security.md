## Joining
- A signed confidentiality agreement before any access.
- Accounts made with the least access needed (policy 04); security awareness talk on day one (this policy set, phishing,
  lost devices, reporting).

## While working
- Security awareness refresh once a year (signed attendance in the evidence folder).

## Leaving (the same day)
- [ ] GitHub, Hostinger, Google Cloud, Razorpay, Play Console, Anthropic access removed
- [ ] `ADMIN_KEY` and `CRON_KEY` rotated if they knew them; their SSH key removed from the server
- [ ] Devices and documents returned; confidentiality reminder signed
- [ ] Noted in the next monthly access review
